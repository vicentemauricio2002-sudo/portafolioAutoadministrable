## 🔑 Datos de Acceso al Panel (Simulación)

Para entrar y revisar el panel de administración (`dashboard_admin.php`), puedes usar los siguientes datos de prueba:

* **Usuario:** `vicente`

> 💡 **Nota académica:** Por temas prácticos de la entrega, estos datos se validan directamente con JavaScript en el archivo `script.js`. Si los dejas vacíos o pones datos incorrectos, el sistema te mostrará una alerta de error en la pantalla.
